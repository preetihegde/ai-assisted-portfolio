## Q: Tell me about your AI-assisted portfolio.

My AI-assisted portfolio is an interactive portfolio website that allows visitors to learn about my experience, projects, technical skills, and research through natural language conversations instead of browsing traditional web pages.

The chatbot, called Uttara AI, is powered by a Retrieval-Augmented Generation pipeline. Portfolio documents are converted into vector embeddings using the Gemini Embedding API and stored in Supabase (pgvector). When a visitor asks a question, the system retrieves the most relevant information from the portfolio knowledge base before generating a context-aware response using a Large Language Model.

The project combines frontend development using TypeScript with a FastAPI backend and demonstrates my experience in full-stack AI development, semantic search, vector databases, and conversational AI systems.
